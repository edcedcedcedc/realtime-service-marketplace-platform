Actual workflow:

Client Flow:
-------------
1. [Login]
2. [Post Job]
    - Title
    - Description
    - Location (Optional)
    - Suggested Budget (e.g., €15)
    - [✓ Accept Bids] (toggle)
3. [Live Job Thread]
4. [Wait for Bids]
    - See incoming bids (e.g., €19, €20, €15)
    - View worker profiles, ratings
    - Optional: Revise suggested budget
5. [Accept Bid/Payment]
    - Confirm selected bid
    - [Stripe Escrow Payment Hold]
        - Charge client (Stripe API)
        - Hold funds until job marked done
6. [Confirm Completion]
    - Real-time updates
    - [Confirm Completion]
        - [Stripe Releases Funds to Worker]
7. [Rate Worker]

--------------------------------------------------

Worker Flow:
-------------
1. [Login]
2. [Live Feed]
    - View new job posts
3. [View Job]
    - See client budget (e.g., €15)
    - If [Accept Bids] = true → show [Place Bid] button
    - If not → show [Accept Job] button
4. [Wait for Acceptance/Bid]
    - Enter bid amount (e.g., €19)
5. [Get Accepted]
    - Notification of acceptance
        - [Stripe: You'll Get Paid After Completion]
6. Do the job
    - Real-time updates
7. [Mark done]
    - Mark "Job Started", then "Job Done"
8. [Get paid]
    - [Stripe Payout to Linked Account]
    - or automatic after client confirmation

--------------------------------------------------

STRIPE is used for:
- Escrow payment hold (when client accepts bid)
- Notification/payment after job completion
- Payout to worker

## 📲 Your Real-Time Job App: Task Categories & Stripe Flows

Let’s break this into **3 categories** you can add to your **Job Feed UI**, and show exactly how each handles **payments** using **1 Stripe integration**:

---

### 🛠️ 1. **Fix & Repair**

**Example jobs:** electrician, appliance repair, plumbing

**🧾 Category Label:** `Fix & Repair`
**💳 Stripe Flow:**

* Client sets **base price** (e.g. \$30/hour or \$40 flat)
* Tasker arrives, inspects
* If materials are needed (extra wire, parts, etc):

  * Tasker taps **"Add cost"**, inputs amount
  * Client gets **in-app confirmation** (e.g., +\$15)
  * Total is **charged once** via Stripe after completion

**✅ Requires optional “add cost” modal**

---

### 🧤 2. **Personal Help**

**Example jobs:** dog walking, grocery pickup, wait in line, elderly help

**🧾 Category Label:** `Personal Help`
**💳 Stripe Flow:**

* Client sets **final budget** when posting (e.g. \$8 for dog walk, \$12 grocery pickup)
* Tasker accepts
* Stripe **pre-authorizes** amount
* Charge is finalized after job

**✅ Fully covered by 1 payment**

Optional: Grocery pickup could include a **“list” or “store name”** field.

---

### 📦 3. **Move & Deliver**

**Example jobs:** package delivery, light moving, object pickup/dropoff

**🧾 Category Label:** `Move & Deliver`
**💳 Stripe Flow:**

* Client sets fixed fee (e.g. \$10 small box, \$25 furniture)
* Tasker accepts
* Stripe payment processed as **flat fee**

Optional: Let user select “I will help lift” vs “Tasker brings help” to change price tier.

**✅ Always fixed fee**

---

### 💳 Stripe Integration Summary

| Task Category  | Stripe Flow                   | Variability |
| -------------- | ----------------------------- | ----------- |
| Fix & Repair   | Base + Optional Add Cost      | Medium–High |
| Personal Help  | Fixed price                   | Low         |
| Move & Deliver | Fixed price (possibly tiered) | Low–Medium  |
