# 🛠️ GitHub Setup & Best Practices

### ✅ 1. **Branches**

| Branch      | Purpose                                 |
| ----------- | --------------------------------------- |
| `main`      | Stable code, auto-deployed              |
| `dev`       | Active development + integration branch |
| `feature/*` | Individual feature branches             |

> Example:
> `feature/login-auth`
> `feature/ws-job-feed`
> `feature/payment-escrow`

### ✅ 2. **GitHub Actions (.yml)**

**File:** `.github/workflows/backend.yml`

```yaml
name: Django Backend CI

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.10'

      - name: Install dependencies
        run: |
          cd backend
          pip install -r requirements.txt

      - name: Lint
        run: |
          cd backend
          black . --check
          flake8 .

      - name: Run tests
        run: |
          cd backend
          python manage.py test
```

**File:** `.github/workflows/frontend.yml`

```yaml
name: React Native Frontend CI

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '18'

      - name: Install dependencies
        run: |
          cd frontend
          npm install

      - name: Type Check + Lint
        run: |
          cd frontend
          npm run lint
          tsc --noEmit

      - name: Run tests
        run: |
          cd frontend
          npm test
```
